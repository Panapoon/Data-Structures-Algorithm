## 🎯 Objectives

Repository นี้จัดทำขึ้นเพื่อฝึกความเข้าใจเกี่ยวกับ

1. การเลือกใช้ Data Structure ให้เหมาะสมกับปัญหา
2. การออกแบบและวิเคราะห์ Algorithm

## 🧠 Algorithm Complexity

ตัวอย่าง Big-O ที่ใช้ในการวิเคราะห์ Algorithm

| Complexity   | Example                      |
| ------------ | ---------------------------- |
| `O(1)`       | Access Array                 |
| `O(log n)`   | Binary Search                |
| `O(n)`       | Linear Search                |
| `O(n log n)` | Merge Sort                   |
| `O(n²)`      | Bubble Sort / Selection Sort |
| `O(2ⁿ)`      | บางปัญหาที่ใช้ Recursive     |
